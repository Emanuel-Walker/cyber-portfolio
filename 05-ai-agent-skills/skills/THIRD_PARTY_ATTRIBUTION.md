# Third-party skill inspiration

This project contains original skills plus skills adapted from public open-source patterns.

## Vercel Agent Skills

Source: https://github.com/vercel-labs/agent-skills

License: MIT, as stated by the upstream project.

Patterns adapted:
- writing/documentation review workflow
- web interface review workflow
- Agent Skills folder and `SKILL.md` conventions

Our `docs-readability-audit` and `web-ui-audit` skills are rewritten for this portfolio's plain-English and builder-focused goals. They are not verbatim copies of the upstream rule sets.

## Meta Muse Gadget SDK

Source: https://github.com/facebookincubator/muse-gadget-sdk

License: Apache-2.0, except upstream-noted third-party/avatar exceptions.

Pattern adapted:
- separate short human README from detailed `AGENTS.md`
- explicit supported hardware/tool versions
- health signals
- exact build/test commands
- "before handoff" quality checklist

Our `repo-onboarding-audit` skill is an original checklist inspired by that documentation architecture.
