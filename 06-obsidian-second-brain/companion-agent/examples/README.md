## Companion patterns

The portfolio copy also includes richer pattern examples under:

```text
patterns/
```

They demonstrate three different companion styles:

- **Muse pattern** = chief-of-staff / planning / project orientation
- **Dot pattern** = reflection / journaling / daily context
- **Grok-style pattern** = lean factual context with hard boundaries

Treat these as architecture examples.

Do not assume the named product automatically supports direct Obsidian sync.

The durable pattern is:

```text
Vault Agent -> curated Context Pack -> Companion Agent -> Vault Capture -> Vault Agent
```
