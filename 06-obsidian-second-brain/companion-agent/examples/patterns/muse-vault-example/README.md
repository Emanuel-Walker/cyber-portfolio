# Muse Vault Example

A chief-of-staff pattern. Muse here is a category, not a product: a self-built or lightly configured agent that handles planning, triage, and recall for one person. This vault is heavier on structure than the Grok or Dot examples because a chief-of-staff pattern thrives on indexes.

## Why this layout fits a chief-of-staff pattern

- **Projects index up front.** The agent reads this to answer "what should Jamie be working on today."
- **A people folder.** The agent recognizes names in meetings and emails and brings context.
- **A dedicated meetings folder.** Short notes per meeting, so the agent can answer "what did I say I would do."
- **A current-season file** so weekly planning does not drift.
- **A rules file that specifies autonomy.** The agent needs to know what it can decide and what to escalate.

## When to use it

Pick this layout when you want an agent that triages your week, keeps a running view of your projects, and prepares you for the next three days without being asked.

## When not to use it

If you want pure reflection, use the Dot pattern. If you want a lean fact store with no routing, use the Grok pattern.
