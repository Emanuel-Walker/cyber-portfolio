# Dot Vault Example

A journal-pattern vault for a reflective companion. Dot by New Computer wound down in 2025, so this layout is for the broader pattern: journal-first agents that build a rolling model of a person out of daily reflections and voice notes.

## Why this layout fits a journal-pattern agent

- **The daily log is the center of gravity.** One file per day. Freeform. Honest.
- **"About me" reads like a self-introduction**, not a resume.
- **Rules file is short and kind.** The agent is a reflective partner, not a drill instructor.
- **Projects index is small on purpose.** The agent is not here to triage your sprint.
- **People folder stays warm.** Who matters to you, not just who you work with.

## When to use it

Pick this layout when you want a companion that listens, reflects, and surfaces patterns over months. Someone to think with at the end of the day.

## When not to use it

If you want a chief-of-staff that moves work, use the Muse pattern. If you want a lean fact store with no reflection, use the Grok pattern.
