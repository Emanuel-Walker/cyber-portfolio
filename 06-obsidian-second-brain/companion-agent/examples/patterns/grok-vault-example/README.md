# Grok Vault Example

A lightweight, agent-facing vault layout optimized for a Grok-style companion. The design assumption is that the agent has selective, not total, recall. It will keep the facts it judges important and forget the rest. So this vault keeps the top-level narrow and the files blunt.

## Why this layout fits a Grok-style agent

- **Short, high-signal top level.** Five files and three folders. Nothing to get lost in.
- **An "about me" that reads like a bio.** Grok anchors on concrete facts. Give it concrete facts.
- **A rules file with hard lines.** Three to seven rules the agent is not allowed to cross.
- **A current-season file** so the agent knows what matters this quarter without rereading six months of logs.
- **A thin daily log** for context trails, not deep journaling.

## When to use it

Pick this layout when you want a fast, factual companion that remembers who you are and what you are working on, without expecting it to be a reflective partner.

## When not to use it

If you want deep journal reflection, use the Dot pattern instead. If you want a chief-of-staff that triages your week, use the Muse pattern.
