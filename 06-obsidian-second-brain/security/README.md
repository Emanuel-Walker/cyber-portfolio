# Security

Read this folder before putting sensitive material in the vault.

## Core distinction

```text
local notes != local AI
```

Your Markdown files may stay on your computer.

A hosted agent may still receive any file content it reads during a task.

## Use this folder for

- local-first threat model
- PII rules
- encryption-at-rest decisions
- backup/sync choices
- private-folder boundaries

## Never store casually

Keep these in purpose-built secure storage:
- passwords
- API keys
- private keys
- authentication recovery codes
- financial credentials
- government identity numbers

The vault is a knowledge system, not a password manager.
