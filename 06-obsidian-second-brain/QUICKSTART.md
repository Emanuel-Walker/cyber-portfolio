# Quickstart

If you have never used Obsidian or a coding agent before, use:

```text
WALKTHROUGH.md
```

It starts from zero:

```text
install Obsidian
-> create a local vault
-> install Codex or Claude Code
-> sign in
-> open the vault folder in Terminal/PowerShell
-> paste one setup prompt
-> verify the folders and rule file
```

You do **not** need to clone this repository.

## Already have Obsidian + Codex/Claude Code?

Create or open an empty vault.

Open Terminal/PowerShell in that vault.

Launch:

```bash
codex
```

or:

```bash
claude
```

Then open `WALKTHROUGH.md` and jump to:

```text
Part 4 — Let the agent build the starter vault
```
