# Templates

Reusable note shapes live here.

Examples include:
- daily note
- weekly review
- project
- person
- meeting
- brain dump
- book note
- idea incubator

## Rule

A template should reduce friction.

If a template has fields you repeatedly leave blank, remove them.

Do not make every note complete a questionnaire.

Some templates use Obsidian Templater syntax.

If you see raw template code in Obsidian, install/configure Templater before using that template.
