# Agent setup

Agent-specific charter templates live here.

## Templates

Use the template that matches your tool:

```text
CLAUDE.md.template
CODEX.md.template
AGENTS.md.template
```

The setup script copies one of these to the vault root.

## Start

Read:

```text
INSTALL.md
```

Then validate with:

```text
Summarize the rules in my charter.
Do not edit any files.
```

and:

```text
Which folders are protected from unrestricted writes?
```

If the agent cannot answer those correctly, do not give it more permissions.
