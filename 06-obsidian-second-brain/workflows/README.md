# Workflows

Each file describes one repeatable job the agent can help with.

Examples:
- clean up an Inbox
- build a daily note
- review past work
- import old conversations
- structure NotebookLM output

## Use one workflow at a time

Do not automate the whole vault on day one.

Start with the workflow that removes the most repeated friction.

## Rule

A good workflow should state:
- input
- allowed folders
- exact output
- approval points
- what not to change

If moving/deleting files is involved, show the proposed changes before applying them.
