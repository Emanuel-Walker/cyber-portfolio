## If you are a recruiter

You do not need to run everything.

For each project, read:

1. the first screen
2. the architecture visual
3. the **Resume starter**
4. the **What this proves / does not prove** section

If you want one technical sample, start with **Crown Jewel Triage** or **Detection-as-Code**.

## If you want to build one

Open that project’s README.

The walkthrough starts from the real prerequisite:

```text
install the tool
-> get the files if needed
-> run the first test
-> see expected output
-> break/change something
-> prove you understand it
```

Git is optional for beginners.

When project files are required, the README shows both:

```text
Code -> Download ZIP
```

and the developer clone path.

## If you want to use one on your resume

Do not copy my project and claim the original build.

Use the project as a reproducible lab.

Then document what **you** did:

- what you changed
- what you tested
- what result you measured
- what failed
- what you learned

Each project README includes a resume starter you can adapt after doing the work.

## Scope
