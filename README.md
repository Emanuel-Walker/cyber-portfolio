## What this is

Nine projects. Six come with files you can read, run or copy. Three are write-ups of work whose code is not in this repo: Maniverse, Neuply and Pip.

I put the newest and most personal work first. The older security labs are at the end.

Each project has **one front door**:

```text
PROJECT/README.md
```

That README explains:
- the problem
- what I built
- how it works
- how to run it, when it has files to run
- what the results were
- what it does not prove

Supporting Markdown remains only when it is part of the project itself, such as a detection strategy, playbook, prompt, sample result, or skill definition.

## If you want to use one on your resume

Do not copy my project and claim the original build.

Use the project as a reproducible lab.

Then document what **you** did:

- what you changed
- what you tested
- what result you measured
- what failed
- what you learned

Each project README ends with what it proves and what it does not. Use that to describe your own work honestly.
